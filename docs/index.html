Install

PS> Install-PSResource -Name TerminalStyles
PS> Import-Module TerminalStyles -DisableNameChecking
PS> tstyles

PowerShell 7 or Windows PowerShell 5.1. tstyles register adds the import to your profile so it loads in every new tab.

Keep your own prompt

PS> tstyles eva -KeepPrompt

Takes the colors, leaves Oh My Posh or Starship alone. In zsh and bash, tstyles shell-init wires the same palette into every new shell.

The dashes describe this tool, not the emulator. iTerm2 would honour a Dynamic Profile — nothing here writes one yet. WezTerm's row is full because this tool generates a Lua module it loads, after one line you add to your own wezterm.lua. They're marked — on purpose: a claimed capability no code delivers means a style reports success, paints nothing, and suppresses the notice that would have explained why. Applying a style tells you which parts your terminal can't show.

Commands

Tab completion works on subcommands and theme names.

tstylesInteractive picker — arrow to preview, Enter to keep, Esc to revert
tstyles umbrellaApply one theme directly, no picker
tstyles listEvery theme with its palette; * marks the active one
tstyles randomPick one at random and apply it
tstyles tune [name]Live-tune brightness, saturation, opacity and font — save the result as your own theme
tstyles font [name]Install a coding font — and, on Windows Terminal, apply it to the profile
tstyles shell-initWire the palette into zsh and bash, not just PowerShell
tstyles resetPut the profile back to its unstyled default
tstyles uninstallRemove the module and the profile loader; your own themes are kept
