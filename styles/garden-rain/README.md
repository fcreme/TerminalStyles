# garden-rain

Ghibli-style garden rainfall. Pixel-art wet stone steps, a metal
bucket and a vivid blue plastic one collecting rainwater, leafy
plants with blue flowers, soft rain streaks. Cool slate-blue base,
vivid plant-green for the cursor and accents, rain-puddle cyan for
strings, bucket-blue for keywords.

No banner — quiet, gentle for long sessions, in the same vein as
forest / golden-forest / snowday.
