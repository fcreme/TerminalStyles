# lain

Serial Experiments Lain. Pixel-art rendering of Lain at her Navi
computer — tangled cables, faint red status lights, the teddy bear,
the small TV. Deep blackish base, lavender-pink monitor glow for
the cursor and primary accents, ghost-pale foreground, vintage
cursor for the late-90s CRT aesthetic.

Navi / Protocol 7 themed banner. *"Present day, present time.
Hahaha."*
