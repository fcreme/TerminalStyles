# neon-rain

Cyberpunk rainy night. Pixel-art dystopia — corporate tower marked "05",
neon yellow sign, matrix-green building displays, lone delivery truck
at a gas-station canopy under steady rain. Deep blue base, neon yellow
for the cursor and primary accents, matrix green for status, muted
dusty foreground.

District-05 / night-sector themed banner and prompt. *"The neon never
sleeps."*
