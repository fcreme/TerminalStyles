# snowday

Quiet winter sunset. Pixel-art creek meandering through a snow-dusted
birch grove, peach-coral light streaming through bare branches, soft
dusty pink on the distant mountain. Deep dusk-blue base, warm
sunset peach for the cursor, sage-green for syntax accents,
stream-blue keywords.

No banner — gentle for long sessions, in the same vein as forest
and golden-forest, but with a colder palette and warmer accent.
