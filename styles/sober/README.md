# sober

The quiet one.

Pure grayscale, single desaturated-teal accent, no banner, no fanfare.
Picking sober just sets the title to `SOBER` and a single-line prompt;
shell startup is silent. The opposite of umbrella.

## Includes

- **scheme.json** — 16-color grayscale palette with one muted teal accent.
- **theme.json** — bar cursor, Cascadia Code regular, padding 16, points
  at a solid-black bundled PNG so picking sober wipes any GIF inherited
  from the previously-active style.
- **profile.ps1** — title `SOBER`, no banner, single-line prompt:
  `<leaf-dir> $ ` with the `$` in muted teal. PSReadLine syntax stays
  grayscale.
- **background.png** — 256×256 solid `#0a0a0a` (the same color as the
  scheme background), so the WT background reads as plain black.
