# tombraider

90s arcade marquee. LED-pixel rendering of the TOMB RAIDER sign with
Lara's silhouette in hot neon magenta, gold "EXT3" call-out label,
cyan-blue highlights. Pure black base, neon magenta cursor and tab
color, arcade gold for strings, electric cyan for variables,
vintage CRT cursor.

Arcade-marquee themed banner. *"Press start."*
